一周真排几天　freqCap

表单上勾的是可训练日，不是「我要练这么多次」。真正排几天由「这一周的量能不能撑起一节够剂量的课」决定。

目标剂量 aim = novice ? 35 : clamp(longestMin || 45, 30, 45)

freqCap = min( 勾的天数,
               max( ceil(weeklyBase / sessionCap),      // 量装不下时必须多排几天
                    floor(weeklyBase / aim),            // 每节要够剂量
                    weeklyBase ≥ 60 ? 2 : 1 ) )         // 排得出两节就别只排一节
L1

周期化

lv + 训练日 → 每天四元组

输出每一天的 (课型, 目标难度, 时长预算, 当日强度上限)。时长预算和强度是两根独立的轴——用分钟数卡预算，用 intensity_level 卡强度。

中周期与周型

中周期长度 L = (阶段=return 或 VI≤3) ? 3 : 4

周型 = 位置 wi % L：
  pos == L-1                        → deload    减量周
  pos == L-2 且阶段 ∈ {build,peak}  → overload  冲击周
  其余                              → normal    常规周
  阶段=return 且 wi==0              → return    回归周
周型目标难度偏移时长系数说明
normal+0.5×1.00只提量，不提强度
overload+1.5×0.92只提强度，必须让出量——否则违反「不同时提高时长与强度」
deload−0.3×0.60砍量保强度（Mujika / Hickson）；至少 2 节，7 天时砍到 6 天留休息
return−1.5×0.80不排 VO2max

角色分配顺序（按真实日期，不按星期编号）

  1. 长课　取间隔最大的一天 + 周末加权。课型由目标决定（现在六个目标全部指向 long_endurance，量撑不起来自动落回 endurance）。
  2. 能力测试　排在主课之前，只在测试周。要求：前一天是休息日、间隔 ≥48h、有功率计 + 骑行台 + 室内。
  3. 主课　剩下的日子里间隔最大的先拿。间隔不够该课型的 min_recovery_hours 时不删课，而是沿降级链降课型。
  4. 轻松骑　紧跟在硬课后面（间隔 <36h）的排轻松骑。课次上限 = 全周的 1/3——Z1 几乎不产生训练适应，超出配额的落到 Z2 有氧。
  5. 其余　有氧耐力。
降级链　vo2max → threshold → sweet_spot → tempo → endurance → recovery
恢复门槛  48h        48h          36h        24h      12h        8h

目标 → 主课优先序　KEY_LADDER

目标主课阶梯（取第一个真正可达的）
efficiency 骑得更省力甜蜜点 → 节奏 → 有氧耐力
health 规律运动身体舒服节奏 → 有氧耐力 → 长距离耐力
comeback 把状态找回来节奏 → 甜蜜点 → 有氧耐力
distance 能骑得更远长距离 → 甜蜜点 → 节奏 → 阈值
cruising 平路骑得更快甜蜜点 → 阈值 → 节奏 → VO2max
climbing 爬坡更轻松阈值 → 甜蜜点 → VO2max → 节奏

阶梯上还有三道额外闸门：课型最低分区 > 当日上限则跳过；II < 4 不排 VO2max；II < 3 不排阈值。全被封死时退到有氧耐力。冲击周把最后一节主课往阶梯深处挪一档——否则排在第 3 位以后的课型永远轮不到。

时长预算分配

角色权重 W　长课 2.2 ／ 主课 1.25 ／ 测试 1.25 ／ 有氧 1.0 ／ 轻松 0.7

周总预算 total = r5(weeklyBase × 周型时长系数)
每槽位预算     = total × W[role] / ΣW，再夹在 [课型 min_minutes, 该槽位上限]

时长天花板 minutesCap
  常规周   = progressMinutes(此前 4 周常规周的时长峰值)
  冲击周   = min(上式, 上一周实际交付分钟)
  减量周   = 上一周实际交付 × 0.68

负荷天花板 tssCap
  常规周   = min(ramp, progressTss(此前常规周可持续负荷峰值))
  减量周   = min(ramp × 0.78, 上一周实际负荷 × 0.75)

progressMinutes(x) = max(x + 10, round(x × 1.10))    // 绝对步长与百分比取大者
progressTss(x)     = max(x + 12, round(x × 1.10))    // 低量端靠绝对步长接管

剂量闸门

周量摊到每一天不够一节正经课时，天数让步、单节保住剂量。一周 60 分钟排两节 30 分钟，比三节 20 分钟的 Z1 空转有价值，而且第三天的休息是如实的休息。

minDose  = min(30, sessionCap)                  // 用户上限低于 30 时跟着走
effTotal = min(total, weeklyBase × 周型系数, minutesCap)

if (nEff > 1 && effTotal / nEff < minDose)
    nEff = clamp(floor(effTotal / minDose), 1, nEff)
    减量 / 回归周不得低于 2 节                   // Mujika：频率不低于常规周八成
if (减量 / 回归周 && nEff ≥ 7) nEff = 6          // 至少留一天完整休息

留哪几天：按日期顺序均匀取，间隔最大

L2

选课

槽位四元组 → course_template_id

课程库只读。硬过滤筛出合规池，七级字典序排序取第一名。选不出就依次放宽，最后兜底到同时长轻松骑。

硬过滤　全部为真才进池

  1. 课型 == 槽位指定课型
  2. 时长 ≤ 预算　且　时长 ≥ 槽位最低时长
  3. 场地：选室内则必须 indoor_ok；选室外则必须 outdoor_ok
  4. 无功率计时：必须 no_power_ok　且　心率可执行　且　不是隐形递进课（%FTP 在爬而心率不动）
  5. 需要骑行台的课，用户得有骑行台
  6. contraindications ∩ 当日 flags == ∅　（含「48h 内高强度」「室外道路环境」）
  7. prerequisites 全部满足（规律周数、最长骑行时长、前一天是否休息）
  8. 课程最高分区 ≤ 当日强度上限　（能力测试豁免，但上限 <Z3 的日子不测）
  9. 上限 ≤Z2 的日子，连热身里 30 秒的激活冲刺也不排
  10. 单节负荷 ≤ sessionTssCap
  11. 主课（及 distance 的长课）额外要求命中所选目标标签

排序　七级字典序，逐级比较

级键含义

顺序本身是规则

soft 必须排在 b3 之前。b3 是「离预算差几个 5 分钟」，它几乎总能分出胜负，放在前面就让「排 90 分钟」这件事替「今天该练什么能力」做了主——实测会导致六个目标的课程序列大面积逐字节相同。时长本来已经被硬过滤夹在区间里了，b3 只是区间内的微调。

三条「到底了」的豁免

第 4、5、13 条都带同一个口子 atFloor：这一周已经全部压到课型时长下限、压不动了。再往下只能砍训练日，而训练日是用户自己勾的，引擎不动。这时如实标出来、不判违规——三条判据必须一致，只给其中一条开口子会让另外两条误报。

越界时的收口顺序

  1. 先卸强度，不动量。目标难度逐档下调（0.5 → 2.0）。训练学上这个取舍是明确的：负荷到顶时先卸强度，有氧时长最后才动。
  2. 再二分砍量。上界不用「打算给的量」，用「这些槽位真吃得下的量」——否则前几轮都在一段完全平的区间里对着同一个结果反复问。
  3. 最后收主课配额。连课型时长下限都超顶时，把质量课配额收一档，腾出的槽位换成有氧/轻松。只在真的降下来时才采纳。
